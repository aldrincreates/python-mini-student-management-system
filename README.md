# python-mini-student-management-system
A simple Student Management System built with Python

A simple student management system created using Python. Featuring a simple student information that tells the user to include their name, course and score. 

Features

- Add Student
- View Students
- Search Student
- Delete Student
- Input Validation using Try and Except
- If-else statement
- Function
- Data structure

Programming Language

- Python

How to Run

1. Download or clone this repository.
2. Open the Python file using a Python editor.
3. Run the program.
